# Smart Expense Manager Frontend

## Tech Stack
- React.js
- React Router DOM
- Axios

---

## Features
- User Signup/Login
- Dashboard
- Add Expenses
- Expense Alerts
- Responsive UI

---

## Installation

### 1. Open terminal inside frontend folder

```bash
npm install
```

### 2. Start Frontend

```bash
npm start
```

Frontend will run on:

```bash
http://localhost:3000
```

---

## Pages
- Login Page
- Signup Page
- Dashboard

---

## Functionalities
- Add Expenses
- View Expenses
- View Alerts
- Dynamic Data Fetching

---

## API Connection
Frontend connects with backend using Axios.

Example:

```js
axios.get("http://localhost:5000/api/expense/all")
```
